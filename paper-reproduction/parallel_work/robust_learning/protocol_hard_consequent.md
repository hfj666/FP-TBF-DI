# 2026-11-05 实际误报上限与单规则后件断点搜索

Rigollet 与 Tong（JMLR 2011，§2.2）将 II 类错误最小化置于 I 类错误上限下。Xie、Xue 与 Roshan（2019，§II）用坐标搜索处理 0–1 损失。本地组合这两个原理。在固定零阈值下，每个已揭示训练前缀的整数误报预算为同状态原 BCE 基线实际 FP 数，直接最小化实际 FN 数。计数相同优先更少 FP。选择同等候选时取距当前坐标最近的区间中点，完全相同时按坐标值升序。每个接受动作均用原预测公式复核 FP 与 FN，要求 FP 不超基线且 (FN, FP) 字典序严格改善。

此臂只改变单条零阶规则的后件。其它参数固定时，分数分子是该后件的一次函数，排序零点后扫描相邻区间。只枚举开区间中点及保留当前解，避开精确贴边的单点解。不改变所有后件共同的截距。每状态从已拟合原模型启动，按原规则顺序至多完整三遍，整遍无变化时提前停止。三遍是事前固定的计算预算，不是原文最佳参数。这是 0–1 计数下的局部搜索，区别于旧固定宽度 BCE 重新拟合。另一臂独立替换所搜索参数块，见 protocol_hard_width.md。

FP 树与增量双聚类、原 64 条规则及 CoveragePool 对照所保存的同状态选择、初始 300 的缩放、128 参数、原参数边界和零阈值沿用。六配置 17/29/43 × 50/100，逐批先预测后更新，仅使用允许 849 行，各划分 213 行排除。误报预算只约束当期训练数据。逐配置报告新增/修复 FN、FP、accuracy、BA、敏感度、特异度。AUC 只作辅助。原 accuracy 与 BA 同升及 BA 至少 4/6 胜的门槛继续适用。单独标出是否漏报净减且误报不增。先以合成数据比较断点扫描与穷举，再重放预测及实际训练计数。

# Round 05 — classwise L2 activation pooling

Exploratory protocol fixed after replaying 23 existing HVDM errors, before any candidate scores. An exact match means all raw antecedent fields match. Of 23 events (9 distinct rows), 3 had no exact positive rule, 16 had exact positive matches but less than half the activation mass, and 4 had majority positive mass but a negative learned score. These are descriptive strata, not causal effects.

Change only activation normalization relative to HVDM. For original firing strengths f and each mined rule label g, let S_g=sum(f), N_g=sqrt(sum(f^2)). Within each group retain f/S_g, and assign group mass N_g/sum(N). Equal rule counts make L2 and RMS yield the same group mass. Fix order 2 as a smooth alternative to sum that emphasizes stronger rules symmetrically; run only this order. Motivation from the pooling distinction in Boureau et al. (https://icml.cc/Conferences/2010/papers/638.pdf), with a local two-group adaptation.

Use the same verified saved rules, HVDM tables, prefix scaling, original confidence and Gaussian firing formula. Refit the same widths and unconstrained zero-order consequents with the same BCE/L2, initialization and bounds, cold 500 iterations. No mining, selection, threshold or other parameter change. Score each next batch at threshold 0. Report six-configuration macro BA and AUC, new and corrected FN versus HVDM and cumulative logistic, and the 23 original events by stratum. Seek BA above logistic without AUC loss or new FN relative to HVDM. Do not select an exponent or threshold from these scores. This is development on reused streams, with no access to the 213 held-out rows per split.

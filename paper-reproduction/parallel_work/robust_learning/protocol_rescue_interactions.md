# 二阶评分交互补救

固定前一轮 categorical_deletion 的分支分数和另外两个分支的归档分数。每批只用已揭示的许可前缀（含初始 300 例）训练，在本分支全部剩余阴性中筛查；历史同评分阴性否决翻转。所有判断阈值为零。

两个特征机制分别用标准化数值评分、独热编码评分水平。保留主效应并追加不同评分项的所有二阶乘积。交互块乘以 sqrt(2/17)，按 18 个主效应和 153 个交互项归一其项数。使用既有 C=1 的 L2 Logistic。每种表示检验完整前缀判阳，以及完整前缀与 32 次分层重采样均判阳两种固定规则。重采样与之前的种子及类样本数相同。翻转时写入完整模型 logit，其他分数逐项保持。没有搜索参数或按当批结果选择分数。第二层仅替换本分支，三路原始分数等权平均。

同时报告每个单分支与融合配置的四类错误变化。晋级要求单分支和融合准确率均增加，两层均无配置新增误报。另记录融合三路共同漏报中被修复的事件数。

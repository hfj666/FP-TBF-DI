# 全前缀辅助证据协议

沿用六配置和已归档 exact_recurrence 策略。每批仅用开批前已揭示的许可标签，包含初始300例。筛查对象为 exact_recurrence 仍判阴的全部记录。有历史同评分阴性时否决翻转。所有分类判断固定以零为阈值。

- numeric：18项原始评分，以前缀均值和标准差标准化后拟合 L2 logistic。
- categorical：18项评分按实际水平独热编码后拟合同样的 L2 logistic。未见水平使用编码器默认的全零处理。
- unanimous：categorical 判阳，且同一前缀按原各类样本数分层有放回抽样的32个重拟合模型全部判阳。编码水平固定为该前缀所见水平。随机种子1105。全票仅检查重采样稳定性。

Logistic 固定 C=1、liblinear、max_iter=1000。三个候选分别与 exact_recurrence 和原始 FP 对照配对。只有六配置合计准确率增加且每配置新增误报为零才晋级。完整保存未晋级结果。
